ตั้งค่าการเชื่อมต่อ Google Sheets

ระบบเชื่อมต่อสเปรดชีตผ่าน Google Apps Script Web App เพื่อซิงค์และจัดเก็บข้อมูลออนไลน์

คู่มือตั้งค่า Google Apps Script (ทำครั้งแรก):
  1. เปิด Google Sheet สเปรดชีต
  2. ไปที่เมนู Extensions (ส่วนขยาย) > Apps Script
  3. วางโค้ด Apps Script และกด Deploy (ทำให้ใช้งานได้) > New deployment
  4. เลือกประเภทเป็น Web app, ตั้งค่า Execute as: Me และ Who has access: Anyone
  5. คัดลอก Web App URL นำมาวางในช่องด้านบน
